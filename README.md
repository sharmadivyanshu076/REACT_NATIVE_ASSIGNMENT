# React Native Assignment

This project is built using React Native and Expo.

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the application:

   ```bash
   npx expo start
   ```

3. Run the app on your preferred platform:
   - Android
   - iOS
   - Expo Go

## Development

You can start building your application by editing the files inside the `src/app` directory.

## Technologies Used

- React Native
- Expo
- TypeScript
